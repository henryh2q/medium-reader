Gửi link bài viết

Muốn tự đưa bài vào ngay bằng extension (cần token)

Dùng được trên Chrome/Edge desktop. Token được admin duyệt thủ công để tránh spam.

Bước 1 — Cài extension

  1. Tải extension: tải file extension.zip, giải nén.
  2. Chrome/Edge → gõ chrome://extensions → bật Developer mode (góc trên phải).
  3. Bấm Load unpacked → chọn thư mục extension/ vừa giải nén.
  4. Mở bài viết bạn muốn gửi → bấm icon extension → dán token (xin ở bước 2 dưới đây) → gửi.
