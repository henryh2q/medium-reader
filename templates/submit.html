Gửi bài viết

Để gửi bài viết vào "Đọc gì hôm nay", bạn cần cài một extension trình duyệt nhỏ và một token truy cập. Token được admin duyệt thủ công để tránh spam.

Bước 1 — Yêu cầu token

Đang chờ admin duyệt…

Trang này sẽ tự cập nhật khi admin duyệt yêu cầu, không cần tải lại. Có thể mất một lúc — bạn có thể đóng trang và quay lại sau bằng link này:

✅ Đã được duyệt!

Token của bạn:

  1. Tải extension: mở thư mục extension/ trên GitHub, bấm "Code" → "Download ZIP", giải nén.
  2. Chrome/Edge → gõ chrome://extensions → bật Developer mode (góc trên phải).
  3. Bấm Load unpacked → chọn thư mục extension/ vừa giải nén.
  4. Mở bài viết bạn muốn gửi → bấm icon extension → dán token ở trên → gửi.
